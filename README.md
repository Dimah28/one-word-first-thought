A deterministic Python program (standard library only) that writes exactly
one word — **defenestration** — to `/output/entry.txt`. Entry for
make.fun's "One Word, First Thought" bounty ($5).

## The word

> defenestration

The act of throwing someone out of a window. Surprising (nobody
expects a word for that), vivid (one sharp image: a body sailing out
a window), and witty (dark humour, Latin roots, a real historical
event in Prague, and a metaphor for being thrown out of anywhere) —
a deliberate pick, not a filler word.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

No network, no randomness, no clock: two runs write byte-identical output.
The entry is 14 characters, inside the 1–24 gate.
